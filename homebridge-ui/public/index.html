Apple Home Features

Everything the robot can show in Apple Home is on, and there is nothing here to switch on or get wrong: rooms, live room tracking, cleaning and suction modes, battery, dock and charging status, and the empty-tank warning all come with the robot. The number below is a preference rather than a feature.

⚠ The switches and sensors need their own pairing — a different QR code

The robot reaches Apple Home over Matter. These switches and sensors are ordinary HomeKit accessories, and they travel on this plugin’s own Homebridge bridge. That bridge is paired separately, so the code you scanned for the vacuum will not bring them in.

In the Homebridge UI: Plugins → homebridge-roborock-matter → the ⋮ menu → Child Bridge Config.

  1. Make sure Enable HAP is turned on. On a Matter-only setup it is often off, and while it is off no QR code anywhere will work.
  2. Save and restart Homebridge.
  3. Come back to the same screen and press Connect to HomeKit. That is the QR code to scan in the Home app.

It is not the main Homebridge QR code on the status page, and not the robot’s Matter pairing code — that one covers the vacuum only. The Homebridge log says which of the three situations you are in every time the plugin starts.

After saving and restarting the Roborock bridge, use the Matter Pairing section below. Apple Home may need both the bridge QR code and the vacuum's 11-digit setup code.
